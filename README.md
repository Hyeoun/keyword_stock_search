# 파이썬용 키워드 관련 주식 리스트 반환 라이브러리
대한민국 국내 주식에 연관된 키워드를 이용하여 관련 주식 리스트를 확인하기 위한 라이브러리입니다.

# 설치 방법
이 패키지는 Python 3.9 환경에서 개발되었습니다.

### 라이브러리 설치
```
pip install git+https://github.com/Hyeoun/keyword_stock_search.git
```
### 라이브러리 업데이트
```
pip install -U git+https://github.com/Hyeoun/keyword_stock_search.git
```

# 사용 예제
### 키워드 목록 리셋
라이브러리 실행 시 최소 1회는 자동으로 다운로드 되지만 이후 변동되는 사항에 대해서는 사용자가 직접 다운로드 해야 합니다.
```
import keywordstk as kss

kss.reset_keywords_stocks()
```
### 키워드 관련 주식 리스트 반환
```
import keywordstk as kss

print(kss.get_stocks("반려동물"))
```
```
['코오롱인더', '풀무원', '바텍', '바디텍메드', '하림', '씨티씨바이오', '메디아나', '팜스코', '에이치피오', '대한뉴팜', '이글벳', '우진비앤지', '오에스피']
```

### 키워드 목록 반환
```
import keywordstk as kss

print(kss.get_keywords()[:5])
```
```
['2차전지', '3D프린터', '5G', '6G', 'AI챗봇']
```

# 기여하기
keyword_stock_search 프로젝트는 오픈 소스 커뮤니티에 기여하고자 하는 모든 분들을 환영합니다. 프로젝트에 기여하는 방법은 다양하며, 버그 신고, 기능 제안, 문서 개선 뿐만 아니라 키워드와 관련 종목들의 추가 및 수정 등이 포함됩니다.
* 버그 신고: 사용 중 발견한 버그를 GitHub 이슈로 신고해 주세요.
* 기능 제안: 새로운 기능에 대한 아이디어가 있다면 이슈를 통해 제안해 주세요.
* 문서 개선: 프로젝트 문서를 개선하는 데 기여할 수 있습니다. 사용자 가이드, 설치 안내, 예제 등의 문서를 개선하여 더 많은 사람이 쉽게 사용할 수 있도록 도와주세요.
* 키워드 및 종목 갱신: 키워드와 엮인 종목들은 계속 변동되며 시기 별로 주목받는 키워드와 종목들은 계속해서 업데이트됩니다. 변동되거나 추가된 내용이 있으면 해당 정보를 프로젝트에 반영할 수 있도록 themes_with_stocks.json 문서를 수정한 후 Pull Request(PR)를 해주세요.

    - 특정 인물 관련주는 추가하는것을 지양해 주세요.
